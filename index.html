Connect Firebase for live sharing

Paste your Firebase web-app configuration into firebase-config.js, enable Firestore, and publish the site. Until configured, this page runs in local demo mode and changes stay in this browser.

  1. Create a Firebase project and register a Web app.
  2. Enable Cloud Firestore.
  3. Copy the web config into firebase-config.js.
  4. Publish the files with GitHub Pages.

For a public shared tracker, configure Firestore Security Rules and consider Firebase App Check. Do not use open read/write rules in a real deployment.
