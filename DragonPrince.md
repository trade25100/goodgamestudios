# Dragon Prince Coordinates

This repository contains the known coordinates of the Dragon Princes.

## Coordinates

| Dragon Prince | X | Y | Position |
|--------------|--:|--:|:--------:|
| Dragon Prince 1 | 653 | 653 | `653:653` |
| Dragon Prince 2 | 712 | 481 | `712:481` |
| Dragon Prince 3 | 540 | 890 | `540:890` |
| Dragon Prince 4 | 321 | 777 | `321:777` |

## Coordinate Format

Coordinates are represented as:

```text
X:Y
```

Example:

```text
653:653
```

Where:

- **X** = horizontal coordinate
- **Y** = vertical coordinate
